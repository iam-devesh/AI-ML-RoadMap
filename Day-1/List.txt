# Day 1: Mastering Python Lists

## 1. What is a List?
A **List** in Python is used to store multiple items in a single variable. 
* **Ordered**: The items have a defined order, and that order will not change (unless you explicitly change it).
* **Changeable (Mutable)**: You can add, remove, and change items in a list after it has been created.
* **Allows Duplicates**: Since lists are indexed, they can have items with the same value.

---

## 2. Creating a List
You create a list by placing items inside square brackets `[]`, separated by commas.

```python
# A list of strings
fruits = ["apple", "banana", "cherry"]

# A list of integers
numbers = [1, 2, 3, 4, 5]

# A list with mixed data types
mixed_list = ["Devesh", 25, True, 99.4]

# An empty list
empty_list = []
```

---

## 3. Python List Indexing and Slicing (Deep Dive)
List items are indexed, meaning each item in the list has an assigned position number. We use these numbers to access or modify specific items.

There are two ways to index items in Python: **Positive Indexing** and **Negative Indexing**.

### A. Positive vs. Negative Indexing

#### Visual Representation:
Imagine a list: `letters = ["A", "B", "C", "D"]`

| Item | "A" | "B" | "C" | "D" |
| :--- | :---: | :---: | :---: | :---: |
| **Positive Index (Left to Right)** | **0** | **1** | **2** | **3** |
| **Negative Index (Right to Left)** | **-4** | **-3** | **-2** | **-1** |

* **Positive Indexing**: Starts at `0` for the first item and increases by 1 to the right.
* **Negative Indexing**: Starts at `-1` for the last item and decreases by 1 to the left.

#### Examples:
```python
letters = ["A", "B", "C", "D"]

# Accessing using positive index
print(letters[0])   # Output: "A" (First element)
print(letters[2])   # Output: "C" (Third element)

# Accessing using negative index
print(letters[-1])  # Output: "D" (Last element)
print(letters[-3])  # Output: "B" (Second element from left)
```

---

### B. List Slicing (Extracting a Sub-list)
Slicing allows you to retrieve a portion of a list. The general syntax is:
`list_name[start : end : step]`

* **`start`**: The index where the slice begins (inclusive). Defaults to `0` if left blank.
* **`end`**: The index where the slice ends (exclusive - meaning this index is **not** included). Defaults to the end of the list if left blank.
* **`step`**: The increment value (how many items to jump). Defaults to `1`.

#### Examples of Slicing:
```python
numbers = [10, 20, 30, 40, 50, 60, 70, 80]

# 1. Basic slice (items from index 1 to 4)
print(numbers[1:5])    # Output: [20, 30, 40, 50] (Note: index 5 '60' is excluded)

# 2. Slice from start (defaults start to 0)
print(numbers[:3])     # Output: [10, 20, 30]

# 3. Slice to the end (defaults end to the last item)
print(numbers[4:])     # Output: [50, 60, 70, 80]

# 4. Using a step (takes every second item)
print(numbers[0:8:2])  # Output: [10, 30, 50, 70]

# 5. Reverse a list using slicing (very common trick!)
print(numbers[::-1])   # Output: [80, 70, 60, 50, 40, 30, 20, 10]
```

### C. Common Mistakes: IndexError
If you try to access an index that does not exist in the list, Python will raise an **`IndexError`**.

```python
fruits = ["apple", "banana"]

# Since fruits only has indices 0 and 1, accessing index 2 will cause an error:
# print(fruits[2])  
# Error: IndexError: list index out of range
```

---

### D. Changing Item Values
You can modify the value of any specific item using its index:

```python
fruits = ["apple", "banana", "cherry"]
fruits[1] = "blueberry" # Replaces "banana" at index 1
print(fruits)           # Output: ["apple", "blueberry", "cherry"]
```

## 4. Predefined List Methods (Functions)
Python has several built-in methods that you can use on lists. They are called using the syntax: `list_name.method()`.

### A. Adding Items
1. **`append()`**: Adds an element to the end of the list.
   ```python
   fruits = ["apple", "banana"]
   fruits.append("cherry")
   print(fruits)  # Output: ["apple", "banana", "cherry"]
   ```
2. **`insert()`**: Adds an element at a specified position/index.
   ```python
   fruits = ["apple", "cherry"]
   # insert "banana" at index 1
   fruits.insert(1, "banana")
   print(fruits)  # Output: ["apple", "banana", "cherry"]
   ```
3. **`extend()`**: Adds elements of another list (or any iterable) to the end of the current list.
   ```python
   fruits = ["apple", "banana"]
   more_fruits = ["cherry", "orange"]
   fruits.extend(more_fruits)
   print(fruits)  # Output: ["apple", "banana", "cherry", "orange"]
   ```

### B. Removing Items
4. **`remove()`**: Removes the first occurrence of a specific value.
   ```python
   fruits = ["apple", "banana", "cherry", "banana"]
   fruits.remove("banana")  # Removes only the first "banana"
   print(fruits)  # Output: ["apple", "cherry", "banana"]
   ```
5. **`pop()`**: Removes and returns the element at the specified index. If no index is specified, it removes and returns the last item.
   ```python
   fruits = ["apple", "banana", "cherry"]
   last_item = fruits.pop()
   print(last_item)  # Output: "cherry"
   print(fruits)     # Output: ["apple", "banana"]

   first_item = fruits.pop(0)
   print(first_item) # Output: "apple"
   ```
6. **`clear()`**: Removes all elements from the list, making it empty.
   ```python
   fruits = ["apple", "banana"]
   fruits.clear()
   print(fruits)  # Output: []
   ```

### C. Searching & Counting Items
7. **`index()`**: Returns the index of the first occurrence of a specified value. (Raises an error if the item is not found).
   ```python
   fruits = ["apple", "banana", "cherry"]
   pos = fruits.index("banana")
   print(pos)  # Output: 1
   ```
8. **`count()`**: Returns the number of times a specified value appears in the list.
   ```python
   numbers = [1, 2, 3, 2, 4, 2, 5]
   print(numbers.count(2))  # Output: 3 (since 2 appears three times)
   ```

### D. Sorting & Ordering
9. **`sort()`**: Sorts the list in ascending order by default. Modifies the original list directly.
   ```python
   numbers = [5, 2, 9, 1, 5]
   numbers.sort()
   print(numbers)  # Output: [1, 2, 5, 5, 9]

   # Sort in descending order
   numbers.sort(reverse=True)
   print(numbers)  # Output: [9, 5, 5, 2, 1]
   ```
10. **`reverse()`**: Reverses the order of the list in-place.
    ```python
    fruits = ["apple", "banana", "cherry"]
    fruits.reverse()
    print(fruits)  # Output: ["cherry", "banana", "apple"]
    ```

### E. Copying Lists
11. **`copy()`**: Returns a copy of the list. (Useful so modifying the new list doesn't change the original list).
    ```python
    original = [1, 2, 3]
    copied_list = original.copy()
    copied_list.append(4)

    print(original)     # Output: [1, 2, 3]
    print(copied_list)  # Output: [1, 2, 3, 4]
    ```

---

## 5. Other Useful Built-in Functions for Lists
Unlike the methods above, these are global functions where you pass the list as an argument (e.g., `function_name(list)`).

* **`len()`**: Returns the number of items in a list.
  ```python
  fruits = ["apple", "banana", "cherry"]
  print(len(fruits))  # Output: 3
  ```
* **`min()`** and **`max()`**: Returns the smallest and largest values in a list.
  ```python
  numbers = [10, 5, 100, 2]
  print(min(numbers))  # Output: 2
  print(max(numbers))  # Output: 100
  ```
* **`sum()`**: Calculates the sum of all elements in a numeric list.
  ```python
  numbers = [1, 2, 3, 4]
  print(sum(numbers))  # Output: 10
  ```
* **`sorted()`**: Returns a new sorted list, leaving the original list unchanged.
  ```python
  numbers = [3, 1, 4]
  new_sorted = sorted(numbers)
  print(new_sorted)  # Output: [1, 3, 4]
  print(numbers)     # Output: [3, 1, 4] (Original is intact)
  ```
